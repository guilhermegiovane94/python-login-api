SUMMARY
-------

Initial commit: Python Login API Test Automation Framework

This commit establishes the foundational structure for the Python login API test
automation project. It includes configuration files, licensing, and documentation
required for the test suite.

DESCRIPTION
-----------

This initial commit sets up the Python login API test automation framework with the
following components:

1. .gitattributes - Git configuration attributes for consistent handling across platforms
2. .gitignore - Git ignore file specifying dependencies, cache, and temporary files to exclude
3. LICENSE - MIT license declaration for the project (Copyright 2026 guilhermegiovane94)
4. README.md - Comprehensive project documentation including:
   - Project overview and technology stack (Python, Pytest, Requests)
   - Requirements (requests>=2.31.0, pytest>=8.0.0, pytest-html>=4.1.0)
   - Installation instructions for Windows environment
   - Test execution commands and options
   - Report generation with pytest-html
   - License information

The project follows the Service Object design pattern with decoupled JSON fixtures
via Fixtures, and focuses on backend API testing for the /api/login endpoint of
the ReqRes API service.

Technologies and tools used:
- Python 3.10+
- Pytest for test framework
- Requests for HTTP client
- pytest-html for HTML test reports
- Fixtures JSON for test data management
- Service Object design pattern

This framework is designed for automated backend authentication testing with
extensible test coverage for the login API endpoint.
